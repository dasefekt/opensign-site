# Open Sign — opensign.co.za

Static one-page site for Open Sign, a Cape Town web studio. No build step: `index.html` at the repository root is the whole site.

## Hosting: Cloudflare Pages
| Setting | Value |
| --- | --- |
| Framework preset | None |
| Build command | (empty) |
| Build output directory | `/` |
| Custom domains | opensign.co.za, www.opensign.co.za |

`_headers` sets security headers, `robots.txt` and `sitemap.xml` are static. `BRIEF.md` is the design brief for anyone editing the page.
